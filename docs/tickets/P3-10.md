## Done (2026-11-10)
- `src/ui/screens/service/Reporting.js` (node `reporting`, mask servicereport): a card "Since the last service" with Distance (719), Time (720) and Labels (721), formatted as on Information › Counters and kept current while the screen is open; below it when the last report was committed and by whom (from the log), or "No service report recorded yet".
- Comment ("What was done"): a multi-line field, 240 characters, 3 lines shown; tapping it unfolds the alphabetical keyboard (starts with a capital) below it and folds the counters away, the check key folds it back. The comment goes into the log, not into a parameter (docx §8.8).
- Date and time plus the logged-in role and user, filled in automatically and updated every 15 s.
- Commit report (L3, node accessAction; locked with a "needs level 3" toast below): confirmation (a note when the comment is empty), then one log entry of type `service` with the comment and the counter values before the reset, the three counters set to 0, the field cleared, toast "Service report recorded". The entry also reaches the diagnosis area while recording (type "Service").
- Fits without scrolling in portrait and both landscape layouts (two columns in landscape; the field gets compact while typing so the keyboard fits).
- Tests: `tests/e2e/reporting.spec.js` (fit, keyboard + commit + reset + log entry, cancel keeps the counters, locked below L3), both projects.
- Figma: frame `reporting / dark / portrait / comment-L3` on "HMI / 04 Screens – Special" (new row). The comment field is plain layers: the Input set has no multi-line variant yet.
