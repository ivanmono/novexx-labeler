## Goal
One token file drives colour, type, spacing, radius and shadow for both themes; utilities such as bg-surface and text-status-run-ink follow the theme switch without rebuild.

## Scope
- src/styles/tokens.css: raw palette, semantic --hmi-* for dark and [data-theme=light], @theme inline mapping to Tailwind utilities
- Status colours identical in both themes, with contrast-safe *-ink variants for text
- Level colours 0-4, branch colours for six main-menu entries
- Type scale caption 12 / label 14 / body-sm 16 / body 18 / body-lg 20 / title 24 / hero 32 / display 48
- Radii xs 8, sm 12, md 16, card 24/23, pill; shadows and glows; gradients

## Acceptance criteria
- [ ] Switching data-theme recolours the whole styleguide without reload
- [ ] Light palette is complete (prototype left gradients, shadows and secondary text dark)
- [ ] Status meaning never relies on colour alone (icon + text, enforced in components)
