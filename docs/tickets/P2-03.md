## Goal
The one row pattern for all 21 parameter screens: label, value, unit, edit affordance, states, help indicator, favourite marker, small low-contrast ParamID.

## Scope
- src/ui/components/ParamRow.js, GroupHeader.js
- States default, pressed, locked, read-only, changed-from-default, with help indicator
- Indent levels 0-2

## Acceptance criteria
- [ ] Value visible in the row without opening
- [ ] Locked rows show a lock and toast "needs level n"
- [ ] Changed-from-default marker visible
- [ ] Row height >= 48 px
