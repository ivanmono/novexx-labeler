- Phase: 2

## Goal
The one row pattern for all 21 parameter screens: label, value, unit, edit affordance, states, help indicator, favourite marker, small low-contrast ParamID.

## Scope
- src/ui/components/ParamRow.js, GroupHeader.js
- States default, pressed, locked, read-only, changed-from-default, with help indicator
- Indent levels 0-2

## Acceptance criteria
- [x] Value visible in the row without opening (unit included; option label for selections; On/Off for toggles)
- [x] Locked rows show a lock and toast "needs level n" (`writeLevel` from access.js)
- [x] Changed-from-default marker visible (brand dot before the value, `data-changed`)
- [x] Row height >= 48 px (`min-h-touch-row`)
