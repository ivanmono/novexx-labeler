# P1-11 - Start-up screen

- Phase: 1
- Size: M
- Status: done
- Depends on: P1-07
- Requirement refs: §8.17 Start-up screen; params 600, 608, 702, 704

## Goal
Logo area, device name and a progress indicator that runs against previous boot durations instead of jumping in steps; not operable.

## Scope
- src/ui/screens/StartupScreen.js
- States: booting, still starting (past 99 %), failed with error text
- Discreet machine type + FW version line

## Acceptance criteria
- [ ] Visible without interaction; progress is continuous
- [ ] Does not stall at 99 %: a "still starting" state exists
- [ ] Failed start shows the error as text
- [ ] Works in portrait and landscape

## Tests
- e2e boot flow, screenshots of the three states
