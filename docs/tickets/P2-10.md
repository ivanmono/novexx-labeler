- Phase: 2
- Size: S
- Status: done (2026-11-09)

## Goal
Action parameters render as buttons with a pressed state and a confirmation when the action moves the machine.

## Scope
- src/ui/components/Button.js action variant
- Confirmation for 2, 6, 7, 800, 803-808

## Acceptance criteria
- [x] Pressed state visible: the row carries an outlined action pill that fills while pressed and stays filled while its confirmation is open (`data-armed`, DT-47)
- [x] Machine-moving actions confirm first (2, 6, 7, 800, 803–808 open a confirmation dialog from the parameter row)
