# P1-01 - Store, persistence, factory reset, targeted re-render

- Phase: 1
- Size: M
- Status: todo
- Depends on: P0-02
- Requirement refs: §3 limited graphics performance; §7.2 live State values

## Goal
A small reactive store holds machine, session, params, ui and data slices. Subscribers patch DOM in place; full screen renders happen only on navigation, to respect the embedded graphics budget.

## Scope
- src/core/store.js: get/set/update/subscribe/select, slice-level change events
- src/core/persist.js: localStorage snapshot of params, users, formats, logs, favourites, session; versioned; factory reset
- Render helpers for in-place patching of rows and values

## Acceptance criteria
- [ ] Setting a parameter notifies only subscribers of that id/slice
- [ ] Reload restores values, users, formats, logs and favourites
- [ ] Factory reset from the dev panel returns every slice to seed data
- [ ] No full-screen innerHTML on a live-value tick

## Tests
- tests/unit/store.test.js (subscribe, select, batch)
- tests/unit/persist.test.js (round trip, version mismatch)
