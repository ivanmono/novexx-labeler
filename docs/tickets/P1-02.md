# P1-02 - Router with explicit back-stack and ref resolution

- Phase: 1
- Size: M
- Status: done
- Redmine: #165211 (https://projects.mono-software.com/issues/165211)
- Depends on: P1-01
- Requirement refs: §6.2 Back returns to where you came from; tree ref nodes

## Goal
Hash router with a history stack that follows the path the user walked, not the tree. Ref nodes resolve to their target so a screen reachable from two places is one screen.

## Scope
- src/core/router.js: routes by screen id and mask type, push/back/replace, stack cap, deep links
- ref-* nodes resolve to target, keep origin branch for the cross-link hint
- Screens registered by kind (menu, list, mask type)

## Acceptance criteria
- [ ] Home > Settings > Interface > Digital IO > Sensors > Start then Back returns to Sensors
- [ ] Opening ref-start shows the same screen instance as Start
- [ ] Deep link #/screen/start opens Start with Back going Home

- tests/unit/router.test.js (stack, ref, deep link)
- e2e navigation flow (P2-15)
