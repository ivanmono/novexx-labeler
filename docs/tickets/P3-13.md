## Done (2026-11-11)
- `src/ui/screens/service/UserModified.js` (node `usermodified`): a generated node on the parameter list screen, like Favourites. Items: every settable parameter (not display / state / action, writable) with a default whose value differs from it, in ParamID order (`modifiedIds`); rows follow the level and the show conditions (`listRows`).
- Rows are the Favourites cards (the screen(s) the parameter lives on in the branch colour, name, ParamID, value with the changed dot) plus "default <value>" under the value. Tapping opens the parameter's editor; a value set back to its default leaves the list at once. Intro line "n parameters differ from their default · tap one to change it"; empty state "All parameters you can see are at their default values."
- `ParamRow` card: optional `defaultText`; `ParamListScreen`: `usermodified` uses the card layout, optional `node.intro`.
- Tests: `tests/unit/usermodified.test.js`, `tests/e2e/usermodified.spec.js` (4 × 2 layouts).
