- Quicklink picker (search or favourites)

## Done (2026-11-02)
- `src/ui/components/DateTimePicker.js`: one column per field (hours : minutes, day . month . year), 60 px
  steppers above and below the value so the finger never covers it; hours, minutes, day and month wrap, the year
  stops at the range (2027–2099). A day that does not exist (31.02.) or a date outside the range is explained
  inline and Set stays disabled — never corrected (§7.3). "Now" takes the device clock. Seconds are not edited:
  Info_Time is stored as `hh:mm:00` and shown as `hh:mm` in the row. Parse / format / validate helpers in
  `src/core/validate.js`.
- Already in place from earlier tickets and covered by the new e2e spec: language (500) re-renders live (P1-05),
  orientation (601) and dark mode (612) apply live (P1-06), logo selection (608) on start-up, home and stand-by
  (P1-11, P1-12, P1-16), quicklink picker for 614–617 with favourites first (P2-12).
- Tests: `tests/unit/datetime.test.js` (6), `tests/e2e/hmi.spec.js` (4 flows × 2 layouts).
- Figma: component set `DateTimePicker · Kind=time|date × State=default|error` (3 variants) on
  `HMI / 02 Components`, node `2073:12576`. No HMI list frame with an open picker yet (P3-22 / P4-09 batches).
- Not done: hold-to-repeat on the steppers (a minute change can take up to 30 taps); worth raising at G2-3.
