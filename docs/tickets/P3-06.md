## Goal
Table of all digital IOs with pin name, direction, function and live state; at L3 outputs can be forced.

## Scope
- src/ui/screens/service/IoTest.js
- Modular row, group header, state indicator; grouping/filter by IO group
- Forcing with visible marking, reset on leave or timeout, "all outputs back to normal"

## Acceptance criteria
- [x] Inputs and outputs distinguishable at a glance; state is an indicator, not text
- [x] Forced marking plus reset-all; explicit warning
- [x] Both L1 and L3 faces designed
- [x] Read L1, forcing L3

## Tests

## Done (2026-11-10)
- `src/ui/screens/service/IoTest.js`: group filter chips (All / MIO card / CPU board, from the machine configuration), a group header per group in "All", TableHeader + TableRow rows, end marker and scroll hint.
- TableRow grew an IN / OUT tag under the pin (grey / teal), a lamp in the state pill (filled dot HIGH on green, ring LOW on grey), an optional force column and a note on forced rows.
- L1/L2 face: no force column, "Forcing outputs needs access level 3". L3 face: switches on output rows only; the first force on a visit asks once (can move the machine, resets after 60 s / on leaving / with reset-all); a forced row shows "Forced · n s"; the bottom strip counts forced outputs and offers "All outputs back to normal". Leaving the screen resets every forced output.
- Live: values are patched in place every tick (no redraw while tapping, scroll kept); the page redraws only when level or the set of forced outputs changes.
- Figma: TableRow set rebuilt with the tag and lamp. Tests: `tests/unit/shared.test.js` (+2), `tests/e2e/iotest.spec.js`.
