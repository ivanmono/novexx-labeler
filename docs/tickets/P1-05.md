## Goal
All UI text comes from resources keyed by TextResID where the Excel provides one. English and German are real; the other 24 languages fall back to English.

## Scope
- src/core/i18n.js: t(key, params), setLanguage, temporary language per session, fallback chain
- src/data/i18n/en.json, de.json for chrome; en.generated.json from the extractor
- Audit helper listing strings whose German is > 30 % longer than English

## Acceptance criteria
- [ ] Switching 500 to German translates chrome and parameter labels
- [ ] Temporary language resets at logout and on restart (§8.14)
- [ ] Unknown language shows English, never a key
