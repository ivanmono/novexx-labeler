## Done (2026-11-10)
- **ListRow** `Kind=value|nav|select × State=default|selected|disabled × Icon × Divider`, ≥ 68 px; the user screen's label/value rows use it. **ListEnd** marker and **scroll indication** (`.scroll-hint` + `mountScrollHint`: fade and chevron while more follows).
- **TableRow** `Kind=input|output × Value=high|low × Forced` + **TableHeader**: pin · function · HIGH/LOW pill · force switch (disabled below L3); a forced output gets an amber edge, tint and "Forced".
- **confirmAction** (ConfirmDialog.js): one pattern for normal / destructive, `whenStopped` refuses with a toast while the machine runs. Figma: the Modal set.
- **ProgressResult** `State=running|success|failure`: phase, bar with %, warning line; result with actions; failure with "what to do next".
- **Placeholder** `Kind=empty|loading|error`; "no USB drive" is the empty kind.
- **FileBrowser** + **PathBar**: path bar, one level up, folders first, files with size/date, foreign files greyed; `mountFileBrowser` wires up / open / pick.
