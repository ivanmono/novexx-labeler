# P1-16 - Stand-by state and wake

- Phase: 1
- Size: M
- Status: done
- Redmine: #165226 (https://projects.mono-software.com/issues/165226)

- Requirement refs: §5.4 status bar stand-by; param 613 HMI_Standby_Timer

## Goal
After the stand-by timer expires the HMI dims to a stand-by screen; any touch wakes it. The status bar has a stand-by state.

## Scope
- src/ui/screens/StandbyScreen.js
- Timer from 613 (0 = off)
- Wake restores the previous screen

## Acceptance criteria
- [ ] Stand-by after 613 minutes of inactivity (dev panel can shorten)
- [ ] Touch wakes without triggering the element under the finger
