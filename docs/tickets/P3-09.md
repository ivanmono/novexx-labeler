## Done (2026-11-10)
- `src/core/errorlog.js` + `errorlog` slice (persisted, 200 entries, FIFO): every error and warning the simulator raises, with the level and user logged in at that moment; a dummy history (9 entries over 16 days) seeded once per device. Texts come from the error catalogue by code, so they follow the language; the catalogue got a "what to do" text per code (dummy).
- `src/ui/screens/service/ErrorHistory.js`: search field (Input) first; tapping it unfolds the keyboard below it, the check key folds it away. Filtering starts at the second character, over the ID (with or without its hyphen: "e207" finds E-207) and the message, while typing; only the list is re-rendered so the keyboard stays.
- Rows newest first: severity tag (icon + High / Medium / Low, red / amber / grey), ID, date and time, role and user in the level colour, message clamped to two lines with a chevron; tapping opens the full message, what to do, severity, time and who was logged in (error dialog for high, info otherwise).
- States: "No errors recorded", "No error matches …", "Type 2 or more characters", count line ("3 of 9 entries"), end marker and FIFO note. Clear history at L3, destructive.
- Tests: `tests/unit/errorlog.test.js`, `tests/e2e/errorhistory.spec.js`.
