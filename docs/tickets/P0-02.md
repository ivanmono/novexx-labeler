# P0-02 - extract-data.mjs: xlsx primary, clickdummy for tree and masks

- Phase: 0
- Size: M
- Status: done
- Redmine: #165200 (https://projects.mono-software.com/issues/165200)
- Depends on: none
- Requirement refs: §2 Reference material; Excel Parameterliste v12; Clickdummy DATA

## Goal
Generate src/data/*.json from the binding sources so screens are data, not markup. The Excel list is primary for parameters; the clickdummy only maps parameters to screens and carries mask specs.

## Scope
- scripts/extract-data.mjs reads docs/sources/Parameterliste-PreSeriesPhase-12.xlsx with SheetJS
- Parses the DATA line of docs/sources/PID_Labeller_HMI_Clickdummy.html for the 62-node tree, items, masks, req specs, links
- Derives control per parameter (toggle, select, number, slider, text, ip, time, date, action, state, display)
- Writes params.json, options.json, menu-tree.json, masks.json, runtime.json, backlog.json, meta.json, i18n/en.generated.json
- Keeps Excel row, TextResID and drawio cell id for traceability

## Acceptance criteria
- [ ] 214 Excel parameters + 127 options extracted; counts in meta.json
- [ ] Every tree item with a ParamID resolves to a parameter; shared IDs appear on several screens but exist once
- [ ] Re-running the script is idempotent (no diff)
- [ ] Labels keyed by TextResID where present (tr<N>), else param.<id> / opt.<id>
