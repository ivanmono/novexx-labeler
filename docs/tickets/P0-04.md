# P0-04 - Export Icons v1 from Figma and build the sprite

- Phase: 0
- Size: M
- Status: done
- Depends on: none

## Goal
Use Mono's rule-based 48 px icons instead of the 24 px PID proposals, bound to currentColor so one file serves both themes and all status colours.

## Scope
- Agent step: download_assets for each of the 67 icon/<name> components (svg)
- scripts/build-sprite.mjs normalises (drops background rects, stroke -> currentColor, no ids) and writes sprite.svg + index.json
- src/ui/components/Icon.js: icon(name, {size, class}) and injectSprite()
- Fallback to docs/sources/pid-icons-24px by name if a Figma icon is missing

## Acceptance criteria
- [ ] 67 SVGs in src/assets/icons, all 48x48, stroke 2, stroke currentColor, no fills
- [ ] Sprite builds idempotently; validate-data finds every tree icon
- [ ] Icons read at 48, 32 and 24 px on dark and light (styleguide section)

## Tests
- npm run data:validate (icon names)
- Styleguide icon grid, G0-1
