# P1-07 - Machine simulator and seed data

- Phase: 1
- Size: L
- Status: todo
- Depends on: P1-01
- Requirement refs: runtime params 1-13; §6.3 home shows state; §8 refresh rate; §5.4 tile disabled (option absent)

## Goal
Dummy firmware: a state machine (Offline, Online, Pause, Run, Alarm, Warning) driven by the command parameters, counters that tick in Run, encoder values, IO toggling, error injection and auto log-off.

## Scope
- src/core/simulator.js with a 1 s global refresh for live values
- src/data/seed/machine.json: machine type, serial, FW version, D-Series flag, crypto chip, installed options (146, 177, 187, 112, 113, bus card)
- Seeds for formats, users, logs, errors, IO pins, USB tree, firmware versions
- Dev panel hooks: set state, inject error/warning, clear

## Acceptance criteria
- [ ] Run increments 709 and 718 at a plausible rate; Pause stops them
- [ ] Alarm_Reset (1) clears an alarm back to Pause
- [ ] State params 8-13 reflect the state; status bar follows
- [ ] Option tiles disabled when the seed says the option is absent
