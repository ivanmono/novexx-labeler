# P2-01 - MenuScreen with tiles and paging

- Phase: 2
- Size: M
- Status: done (2026-11-02)
- Depends on: P1-02, P1-09
- Requirement refs: §3.2 six tiles per page; §5.4 Menu tile, Paging control; §6.1 colour code

## Goal
Generic menu screen: up to six tiles per page, pager with first/middle/last states, branch colour, tile with icon, label and sub-line.

## Scope
- src/ui/screens/MenuScreen.js, components/MenuTile.js, Pager.js
- States default, pressed, disabled (option absent per seed/machine.json)
- 2 columns portrait, 3 columns landscape

## Acceptance criteria
- [x] Never more than six tiles; more entries page with arrows and indicator (`paginate`; no menu in the
      current tree exceeds six, so the pager shows on the components sheet only)
- [x] Disabled tiles for absent options (overrides.json optionGates → node.gate; Option_* parameters and
      seed/machine.json capabilities; tiles re-enable live when the option is switched on)
- [x] Tile touch area >= 60 px (tiles are 120 px high, 218 px wide in portrait)
