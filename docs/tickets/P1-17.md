# P1-17 - Tokens bound in the generated Figma frames

- Phase: 1
- Size: M
- Status: done
- Depends on: P0-08, P1-15
- Requirement refs: §5.1 Colour, §5.2 Themes, §10 Deliverables (tokens for both themes)

## Goal

Every generated screen frame uses the HMI variables and text styles instead of raw values, so a designer tweaks a
token once in Figma and the change is portable to `src/styles/tokens.css` (and the other way round), and a frame
switches theme by flipping its `HMI Colour` mode.

## Scope

- `serialize-dom.js`: name the token behind every colour (fill, text, border, icon), radius and font. Source of
  truth is the Tailwind utility on the element (`bg-surface`, `text-level-3`, `bg-status-error/15`), fallback is
  the computed value matched against the probed `--hmi-*` variables of the current theme (first in priority order).
- `build-frames.js`: bind `colour/*` variables on fills, strokes, text and icon strokes (opacity modifiers become
  paint opacity on a bound colour), `radius/*` on uniform corners, `HMI/*` text styles on exact matches and
  `type/size/*` + `type/family/*` variables otherwise; set the frame's `HMI Colour` mode from the captured theme.
- Mapping `--hmi-<name>` ↔ `colour/<name>` documented in docs/FIGMA.md (the only renames: `status-X-ink` →
  `status-ink/X`, `keyboard-key` → `key`).

## Not in scope

Follow-up (not started): make the `--hmi-gradient-*` stops reference the raw palette in `tokens.css` and bind the
gradient stops to `colour/*` variables, so a mode flip also switches the page background and card borders.

- Spacing variables (frames are absolutely positioned, no auto layout to bind padding/gap to).
- Gradients and shadows (CSS tokens `--hmi-gradient-*`, `--hmi-shadow-*`, `--hmi-glow-*` stay raw in Figma; no
  effect/paint styles yet).
- Primitives (`HMI Primitives`) are never bound directly; semantic `colour/*` only.

## Acceptance criteria

- [x] In home and login frames, no solid fill, stroke or text colour whose value equals a semantic token is unbound (only `text-black` / `text-white` literals and the 23 px wordmark stay raw)
- [x] Flipping the `HMI Colour` mode of `home / dark / portrait / ready-L0` to Light produces the light frame's colours
      (verified by screenshot: every bound colour switches; the page, card-border and card gradients stay dark because
      gradient tokens are not bound yet, see the follow-up below)
- [x] Text layers use `HMI/*` styles where the type scale matches, bound size/family variables otherwise
- [x] Rebuilding a frame keeps the bindings (no manual re-linking)
